## 重大決策：放棄 GCP VM，改用 Cloudflare Workers

原訂計畫是開一台 Google Compute Engine 的 e2-micro 跑 discord.js。查證後改變方向，原因：

1. **GCP 的「永久免費」有前提** —— Always Free 額度只對已升級的付費帳戶生效。
   不升級的結果不是免費繼續跑，而是 90 天試用結束後直接停機。
2. **流量是隱藏成本** —— GCP 免費額度每月只有 1 GB 對外流量。
   若機器人會上傳圖片到 Discord，很容易超標。
3. **需求不需要 Gateway 常駐連線** —— 確認過所有功能（提示詞查詢、
   按鈕自助領取身分組、管理員指令）都是「使用者主動觸發」，
   可以走 Discord 的 HTTP Interactions 模式，不需要一直開著一台機器。

改用 Workers 之後：不用信用卡、不會過期、不用維運伺服器，
而且 R2 的物件儲存**傳輸完全不計費**，正好繞開 GCP 最貴的那一項。

### 代價
- `discord.js` 不能用（需要 WebSocket 常駐連線），改用 `discord-interactions` + 直接呼叫 REST API。
- 收不到 Gateway 事件：一般聊天訊息、成員加入離開、語音狀態。
  → 新人自動發身分組改用 Discord 內建 **Onboarding**，
    關鍵字過濾與防洗版改用內建 **AutoMod**。

## 機密的處理方式

**唯一的機密是 `DISCORD_TOKEN`。**

- 正式環境存在 Cloudflare secret（`npx wrangler secret put DISCORD_TOKEN`），已設定完成。
- 本機開發存在 `.dev.vars`，**該檔案被 `.gitignore` 擋住，不會進版控**。
- Application ID 和 Public Key 不是機密（公開金鑰的用途就是供外界驗簽），
  已移到 `wrangler.jsonc` 的 `vars`，所以正式環境只需要管理一個 secret。

## 換設備接手步驟

程式碼在這個 repo：

```bash
git clone <這個 repo 的網址>
cd dutu-discord-bot
npm install
```

`.dev.vars` 不在版控裡，要手動重建：

```bash
cp .dev.vars.example .dev.vars
```

四個值分別是：

| 變數 | 從哪拿 |
|---|---|
| `DISCORD_TOKEN` | 從舊機器的 `.dev.vars` 用安全管道帶過去（密碼管理員之類）。<br>或到 Developer Portal → Bot → Reset Token 產生新的 —— **但重置後務必同步更新 Cloudflare secret**，否則線上機器人會失效 |
| `DISCORD_APPLICATION_ID` | Developer Portal → General Information |
| `DISCORD_PUBLIC_KEY` | 同上 |
| `DISCORD_GUILD_ID` | 留空即註冊為全域指令 |

> 重置權杖後記得同步更新 Cloudflare 的 secret，否則線上的機器人會失效。

再登入 Cloudflare：

```bash
npx wrangler login
```

D1 資料庫和已部署的 Worker 都在雲端，不需要重建。

## 環境備忘（Windows）

踩過的坑，換設備可能會再遇到：

- **PowerShell 預設禁止執行指令碼**，`npx` 會失敗。
  解法：`Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned`，
  或改用 `npx.cmd`。
- **wrangler 指令必須在專案目錄下跑**，否則讀不到 `wrangler.jsonc`，
  會報 `Required Worker name missing`。
- **PowerShell 5.1 的 `Invoke-WebRequest` 預設 TLS 版本太舊**，測試網址請用 `curl.exe`。
- 專案路徑含中文與全形字元，目前運作正常。
